Stoa · 股市 Agent  Windows 绿色版

1. 把整个文件夹解压到任意位置（路径里最好不要有空格以外的特殊符号）。
2. 双击 Stoa.exe，直接打开 Stoa 窗口（用 Windows 自带的 WebView2 内核，不开浏览器、没有黑色控制台）。
3. 第一次运行会用记事本打开 .env：
     LLM_PROVIDER=deepseek
     LLM_API_KEY=sk-你的密钥
   填好保存，关掉 Stoa 窗口，再双击 Stoa.exe。
   没填密钥也能看行情，只是不能对话。

关闭 Stoa 窗口 = 退出。出问题时看 %LOCALAPPDATA%\Stoa\stoa.log。
极少数没有 WebView2 的老系统会改用 Edge 的无地址栏窗口打开。

卸载：双击「卸载 Stoa.exe」。它会先关掉正在运行的 Stoa，问你要不要连数据一起删，然后删除整个文件夹。不写注册表、不留服务。
数据（记忆、判断账本、自选股 config.yaml、.env）都在
  %LOCALAPPDATA%\Stoa
升级时直接用新版文件夹替换，数据不会丢。

Windows 弹出“已保护你的电脑”时，点“更多信息 → 仍要运行”（程序没有付费签名）。

若双击 Stoa.exe 没反应，改双击「启动.bat」（带黑色窗口，能看到报错）。
