目标：知道市场在聊什么、谁在真金白银地押注，把噪音和信号分开。

1. 新闻：get_news(symbol) 近 7–30 天；按「多家媒体同时报道」的事件合并成一条，记下首发时间。
2. 社区讨论：web_search 依次搜「<名称> 雪球」「<名称> site:x.com」「<ticker> reddit」「<名称> 股吧」，读 2–3 个点赞/转发/评论最多的结果（fetch_url）。只摘观点，不摘谣言里的数字。
3. 真金白银：A股 get_fund_flow（主力 5 日）、get_dragon_tiger（游资/机构席位）、get_chips（融资余额变化）；美股 get_options（Put/Call、IV）、get_insiders、get_short_volume。
4. 排序：每条主题按（来源数 + 互动热度 + 资金是否同向）打分，用 calc 算，不要凭感觉；资金方向和舆论相反的主题要单独标出来。
5. 回答：
   - 现在在聊的 3–5 个主题，各一句 + 热度 + 资金是否同向 + 出处；
   - 分歧点：多空各自最强的一条论据；
   - 噪音：没有资金验证、只有单一来源的说法；
   - 一句提醒：热度高不等于会涨，舆情择时同样不显著。
