---
name: market-recap
description: 盘后复盘：问「今天市场怎么样」「复盘一下」「情绪如何」或写晚报时用；大盘 + A股情绪 + 板块资金 + 自选股 + 判断复盘
---
1. market_overview：A股/港股/美股主要指数涨跌。
2. get_market_mood：涨停/炸板/跌停家数、炸板率、最高连板、连板梯队、涨停最多的行业、行业与概念主力资金流入/流出前五。
   读法：炸板率 >40% 或跌停数 > 涨停数 = 情绪差；最高连板降到 3 板以下 = 退潮；连板梯队完整（1→2→3→4 都有）= 情绪健康。
3. 自选股：watchlist(list) 后 get_quotes 一次取齐，挑涨跌幅最大的 2–3 只用 get_news 找原因。
4. 账本：call_stats 看最近判断的对错，到期的复盘结论写进来。
5. 输出结构：一句话定性（如「放量普涨，情绪回暖」）→ 指数 → 情绪数据 → 资金流向的板块 → 自选股要点 → 明天要盯的事（财报日、解禁日用 earnings_calendar / get_corporate_events）。
6. 有新的经验（比如某个情绪读法这次不准）用 memory 写进 MEMORY.md。
